# Установка LocalDocRenamer

В комплект входят Qwen3 4B GGUF, llama.cpp, OCR с русским и английским языками и
среда выполнения. Устанавливать Python, Office, Tesseract или llama.cpp не нужно.
Приложение ничего не скачивает при обработке документов.

## Windows 10 и 11, 64 бита

1. Распакуйте архив поставки.
2. Запустите `LocalDocRenamer-Setup-Windows-x64.exe` и завершите установку.
3. Запустите LocalDocRenamer через меню Пуск или ярлык.

Установка требует прав администратора, чтобы создать правила запрета исходящих
соединений для программы и комплектных обработчиков. Если Windows Firewall
отключен, приложение остановит обработку с объяснением причины.

## Intel Mac, macOS High Sierra 10.13 и новее

1. Откройте файл `.dmg`.
2. Перетащите `LocalDocRenamer.app` в Applications / Программы.
3. Запускайте приложение из папки Программы. После копирования образ можно извлечь.

Год выпуска компьютера не определяет версию установленной macOS. Для сборки
Mac 2011 требуется как минимум High Sierra 10.13 и процессор с AVX. На более
ранних системах этот комплект не запускается. Проверка минимальных версий
библиотек не заменяет испытание на конкретном старом компьютере.

Для модели 4B желательно от 8 ГБ оперативной памяти; на старом процессоре анализ
может занимать заметное время. Производительность на вашем Mac ещё не измерена.
Модель 8B в стандартный комплект не входит; локальный GGUF можно выбрать вручную.

## Первый документ

1. Нажмите Файлы или Папка, либо перетащите документы в окно.
2. Нажмите Анализировать и дождитесь завершения.
3. Откройте строку через Проверить. Сверьте поля и имя с оригиналом, исправьте ошибки.
4. Отметьте подтверждение и сохраните проверку.
5. Нажмите Переименовать проверенные.

Файлы с ошибкой чтения, OCR или JSON не переименовываются. Для отмены нажмите
Отменить переименования. Если содержимое файла изменилось или прежнее имя занято,
программа остановит восстановление этого файла и покажет причину.

Обрабатывайте документы на локальном диске. Сетевые пути заблокированы.
Для переименования требуется файловая система с жесткими ссылками: например,
NTFS на Windows или APFS / HFS+ на Mac. exFAT для этой операции не подходит.

Модель может ошибаться даже при наличии подтверждающей цитаты. Перед первым
пакетом проверьте работу на копиях нескольких документов.
