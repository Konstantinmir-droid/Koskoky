# Проверка LocalDocRenamer

Дата: 18 октября 2026 года. Проверяемый общий коммит приложения:
`b51fa9a3e4ddd89cb2f94918c29e559085953eac`.

## Автоматические проверки исходного кода

50 тестов прошли на Linux x86_64 с Qt offscreen. Они проверяют строгую схему JSON,
календарные даты, ИНН, null для неподтвержденных полей, восстановление только
равнозначных дословных дат/сумм/валют, имена Windows, коллизии, ручное подтверждение,
изменение содержимого, переименование без перезаписи, восстановление после прерывания,
отмену, экспорт без исполнения формул, защиту исходника от перезаписи экспортом,
пути ресурсов, локальность дисков и запрет Python-сокетов с последующим импортом SSL.

Интерфейс фактически создан и отрисован Qt в offscreen-режиме. Это подтверждает
создание виджетов и работу проверенных действий, но не удобство на любом экране.

## Нативные сборки

- [Windows, сборка 39116220531](https://github.com/Konstantinmir-droid/Koskoky/actions/runs/39116220531)
- [Intel Mac, сборка 39116224426](https://github.com/Konstantinmir-droid/Koskoky/actions/runs/39116224426)

Оба задания завершились успешно. В каждом прошли 50 тестов исходного кода.
Windows: упакованное приложение и затем установленная через созданный EXE копия
вернули status=passed по всем пяти проверкам self-test. Отчеты исходного и
установленного приложения сохранены также в verification/.
Mac: прошли self-test упакованного приложения, аудит 148 Mach-O файлов
(минимальная ОС не выше 10.13), ad-hoc подпись, создание DMG, его монтирование
и проверка подписи приложения внутри образа. Полный JSON self-test входит в архив.

Скачать:
- [Windows EXE, ZIP 2,57 ГБ](https://github.com/Konstantinmir-droid/Koskoky/actions/runs/39116220531/artifacts/12132549442)
- [Intel Mac DMG, ZIP 2,58 ГБ](https://github.com/Konstantinmir-droid/Koskoky/actions/runs/39116224426/artifacts/12132803707)

Это архивы GitHub Actions, срок хранения до 25 октября 2026 года, для скачивания
нужен вход в GitHub. Контрольные суммы установщиков находятся в SHA256.txt внутри
архивов. Метаданные, SHA-256 самих ZIP и идентификаторы сборок: verification/builds.json.

Сборки используют только синтетические документы. В self-test входит реальный
Qwen3 4B Q4_K_M и реальный Tesseract, а не имитация ответов. Запуск выполняется
упакованным приложением с очищенными переменными Python/PATH. На Windows проверяется
также копия, установленная полученным EXE. Mac DMG монтируется и проверяется подпись
приложения внутри образа. Все шаги обязательны для успешного задания.

## Исправления по обнаруженным отказам

1. Устранен сбой нативного sampler llama.cpp: регулярное выражение суммы заменено
   на корректно конвертируемое в GBNF; перед генерацией проверяется создание sampler.
2. Устранен аварийный выход Qt на Mac: используется проверенная связка PyQt5/Qt5
   для старой ОС, добавлены отдельные проверки завершения нативных библиотек.
3. Для Qt на Mac libjpeg.8 собирается с целевым macOS 10.13; исключается зависимость
   от современной Homebrew-библиотеки, требующей macOS 14.
4. Запрет сокетов сохранен в виде класса socket.socket: импорт SSL после включения
   защиты больше не ломает проверку JSON.
5. Канонические ответы модели для даты, суммы и валюты сверяются с точными
   равнозначными фрагментами исходного документа. Отсутствующие значения остаются null.

## Что эти проверки не доказывают

Не проводилась установка на физических Windows 10/11 без средств разработки и
на физическом Mac 2011 с High Sierra. CI использует Windows Server 2022 и macOS 15
Intel. Проверка минимальных версий Mach-O и отключение AVX2 не заменяют запуск на
конкретном старом компьютере. Производительность на Mac пользователя не измерена.

Не проводились независимый захват всего нативного сетевого трафика, испытание
отключением питания, оценка точности на представительном наборе реальных документов,
проверка всех вариантов DOC/XLS и всех локальных GGUF. Проверка системной защиты
подтверждает применение запрета сети, но не является отдельным сетевым аудитом.

Семантические ошибки нейросети возможны даже при наличии цитаты. Переименование
всегда требует ручного подтверждения. Ограничения форматов перечислены в README_RU.md.
Developer ID, Apple notarization и коммерческая подпись Windows не выполнялись.

Следовательно, успешные сборки являются проверенными установочными кандидатами,
а полная приемка всех требований на целевых физических системах остается отдельным этапом.
