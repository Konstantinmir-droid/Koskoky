# Проверка текущего исходного проекта

Дата: 18 октября 2026. Среда: Linux x86_64, Python 3.12, Qt offscreen.

39 автоматических тестов прошли. Полный вывод: test-results.txt.
Проверена компиляция Python-файлов. Интерфейс создан и отрисован фактическими
Qt-виджетами в offscreen-режиме. Это не проверка внешнего вида/запуска на Windows/macOS.

Проверены: строгая схема JSON, несуществующие календарные даты, недопустимые типы,
отсутствующие/лишние поля, обнуление значений без цитат, некорректный ИНН,
десятичная сумма, сохранение расширения, запрещенные имена, коллизии регистра,
запрет перезаписи, блокировка после изменения содержимого, ручное подтверждение,
блокировка критических ошибок, восстановление имени, прерывание между link/unlink,
сохранение исходника при отсутствии поддержки hardlink, конфликты и изменение
содержимого при отмене. Проверены синтетические текстовый PDF, DOCX, XLSX, CSV/TXT,
кодировки, ошибка отсутствующего OCR. GUI: редактирование и подтверждение,
экспорт JSON/XLSX, запрет формул из реквизитов и экспорта поверх входного файла.

Не проверены: загрузка/вывод реальных Qwen3 4B/8B, конверсия данной схемы в грамматику
у выбранной версии llama.cpp, качество извлечения, реальный rus+eng OCR, Windows
antiword/DOC, старый XLS, упаковка PyInstaller, компиляция Inno Setup, установка,
запуск без Python, поведение Defender/SmartScreen, Windows 10/11, macOS, реальный
сетевой трафик и отсутствие обращений нативных библиотек, отключение питания.

В архиве нет модели и нативных runtime-компонентов. EXE, APP, DMG отсутствуют.
Выбраны Windows 10/11 x64 и macOS Intel. Нужны версия macOS и отдельные нативные сборки.
39 тестов не являются подтверждением выполнения полного ТЗ. Проверка данных
нейросети по цитатам уменьшает риск выдумок, но не доказывает правильность смысла.
Первичные документы компонентов перечислены в README_RU.md.


Добавлены сценарии Windows Setup.exe и macOS Intel APP/DMG, общий PyInstaller spec,
workflow GitHub Actions, build-time получение публичных моделей/OCR и встроенный
синтетический self-test. Проверены синтаксис Python/spec, bash -n и разбор workflow YAML.
Семь новых тестов проверяют пути ресурсов/настроек, portable state и обработку
локального/сетевого тома Darwin с имитацией системного вызова. Реальные statfs64,
нативные сборки, workflow и self-test с Qwen еще НЕ запускались.
